이 웹사이트를 친구들에게 공유하는 방법

인터넷에 무료로 올려서 누구나 접속하게 만들 수 있습니다.

1 Netlify Drop (1분 초간단 방법 - 무료)

1. app.netlify.com/drop 에 접속합니다.
2. 만들어진 index.html 파일을 마우스로 드래그하여 올려놓습니다.
3. 즉시 배포된 고유 인터넷 주소(URL)가 생성되어 친구들에게 카톡으로 보내면 됩니다!

2 GitHub Pages 또는 Vercel 이용

개발자용 무료 호스팅인 GitHub에 저장소를 만들고 Pages를 켜거나, Vercel에 커밋하면 나만의 커스텀 도메인으로 포토부스를 평생 무료 운영할 수 있습니다.

3 HTML 파일 직접 전달

웹사이트를 올리지 않고 index.html 파일 자체를 친구에게 보내도 브라우저로 바로 실행 가능합니다.
